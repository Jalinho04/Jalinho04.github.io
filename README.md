# 🛡️ Halit — Portafolio de Ciberseguridad & Desarrollo

Portafolio personal minimalista y oscuro (*clean dark mode*) desarrollado para **Halit**, estudiante de **primer semestre de Ingeniería en Sistemas** apasionado por la **ciberseguridad**, el análisis de redes y el desarrollo de software seguro.

---

## ⚡ Características Principales

- **🌑 Estética Clean Dark & Minimalista:** Paleta de colores `#07090e` con acentos de seguridad (*emerald*, *cyan*, *purple*) y efectos sutiles de desenfoque de vidrio (*glassmorphism*).
- **🎓 Perfil Académico & Enfoque:** Destaca tu formación actual como estudiante de 1er semestre de Ingeniería en Sistemas, tu pasión por la seguridad informática y tu stack en Python, JavaScript y TypeScript.
- **🕸️ Red de Nodos Interactiva (Canvas):** Fondo dinámico con partículas interconectadas que reaccionan con física suave al cursor del ratón, emulando una red de monitoreo y sensores.
- **💻 Terminal CLI Interactiva:**
  - Ábrela con el botón **`CLI`** en la barra superior, en el botón del Hero o presionando **`~`** (o `Ctrl + ~`).
  - Comandos interactivos en español: `whoami`, `carrera`, `skills`, `projects`, `audit`, `matrix`, `cat flag.txt`, `contact`, `clear` y `exit`.
- **🔤 Efecto Decodificador Hacker:** Animación de desencriptación dinámica de texto en los títulos principales al cargar y al pasar el puntero.
- **📁 Filtrado de Proyectos:** Filtra proyectos por categorías: *Seguridad Web*, *Monitoreo de Red*, *Herramientas CLI* o *Todos*.
- **📱 100% Responsivo y sin dependencias pesadas:** HTML5 semántico, Tailwind CSS y JavaScript moderno nativo. Listo para abrir directamente en cualquier navegador o publicar en GitHub Pages.
