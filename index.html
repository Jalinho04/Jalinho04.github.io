Cerberus Threat Sentinel

Sistema automatizado para análisis de tráfico y detección de patrones de red sospechosos. Desarrollado en Python con procesamiento asíncrono para inspeccionar paquetes y clasificar eventos de riesgo.

Seguridad en Aplicaciones Web

AegisGate: Firewall de Aplicación Web (WAF)

Módulo de protección para servicios backend y APIs. Detecta y bloquea peticiones maliciosas (inyecciones SQL, ataques XSS y abuso de peticiones) mediante limitación de tasa y validación estricta de esquemas.

TypeScript Node.js Redis OWASP Top 10
v1.1.2 // Código Abierto Ver repositorio
Herramienta de Reconocimiento

VoidPulse: Reconocimiento & Auditoría de Dominios

Utilidad de consola multihilo para mapear la superficie de exposición de dominios. Consulta certificados públicos de transparencia (CT logs) y resuelve registros DNS de forma simultánea con exportación de datos.

Python AsyncIO Seguridad DNS CLI Scripting
v3.0.1 // Utilidad CLI Ver repositorio
Criptografía & Almacenamiento Seguro

CipherVault: Gestor de Claves con Conocimiento Cero

Almacén criptográfico local con cifrado autenticado AES-256-GCM y derivación de contraseñas maestras mediante Argon2id. Enfocado en la protección contra volcados indebidos de memoria.

TypeScript Web Crypto API Argon2 Buenas Prácticas
v0.9.4 // En Desarrollo Ver repositorio

Mi Trayectoria & Pasión por la Seguridad

¡Hola! Soy Halit. Actualmente soy estudiante de Ingeniería en Sistemas cursando mi primer semestre. Desde el primer día de mi formación académica, tengo una meta clara: especializarme y destacar en el apasionante mundo de la ciberseguridad.

Me fascina entender cómo operan las computadoras y las redes desde sus bases fundamentales: cómo viaja un paquete de datos, qué ocurre en la memoria durante la ejecución de un programa y de qué manera pequeños fallos de diseño pueden convertirse en vulnerabilidades críticas.

En paralelo a mis materias universitarias, dedico tiempo constante al autoaprendizaje práctico desarrollando proyectos con Python, profundizando en el ecosistema de TypeScript y JavaScript, y resolviendo laboratorios para afinar mi pensamiento analítico.
